# Independent answer-key verification — October 21, 2026

## Method
1. **Blind pass.** Six independent reviewers answered all 599 practice questions (449 quiz + 150 mock) from the stem and options only, without seeing the stored key or explanation. Calculations were recomputed; defects were flagged.
2. **Comparison.** Blind answers were compared with the stored keys programmatically.
3. **Adjudication.** Every disagreement and every flagged defect (127 items) went to a second review that saw the key, explanation, and blind reasoning, verified against primary sources (FDA labeling, current-to-2024 guidelines, PubMed), and repaired the item so exactly one option is defensibly correct.
4. **Rationales.** Per-option rationales were rewritten for every changed item that had them, so they cannot contradict the final key.
5. **Guards.** `tests/content-integrity.test.js` enforces structure, uniqueness, and the lithium ranges on every build.

Answer basis: guidance as of 2024 (the course the notes follow). Later changes appear as "Updated since 2024" notes; keys were not moved to post-2024 guidance.

## Results
- Blind agreement with stored keys: **587 of 599 (98.0%)**; mock bank 149 of 150.
- Adjudicated: 127 items. Verdicts: fine 8, fixed_ambiguity 66, fixed_calc 6, fixed_fact 43, key_wrong 4.
- Items changed: 119. Answer keys corrected: 4.
- Also merged 41 duplicate glossary terms and 5 duplicate drug monographs; aligned lithium targets in nine places to the 2024 chapter (0.8–1.2 mEq/L acute mania; 0.6–1.0 mEq/L maintenance).

## Limits
This is an AI-assisted review, not a licensed pharmacist's sign-off. Independent pharmacist review remains the gold standard and is still pending. Readers can report any suspected error from every question and card.
